# Lotus BPO – MRI Conference Deck (Bali, 23–25 Oct 2026)

**Open:** `Lotus BPO - Conference Deck.pptx` (15 slides, 16:9, speaker notes on every slide).

- Slide transitions: fade on the title slide, push on all others.
- Content fades in on its own, a group at a time — no extra clicks needed.
- To rebuild after edits: `npm install && npm run build` (logo and office photos are in `assets/`).

## Print materials

- `Lotus BPO - Brochure (A4 Tri-fold).pdf`: 2-sided A4 landscape, folds into 3 panels.
- `Lotus BPO - Flyer (A4).pdf`: 1-page A4 handout.
- To rebuild after edits: `npm run build:print` (source pages are in `print/`).
